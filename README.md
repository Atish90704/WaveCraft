# WaveCraft
A desktop audio signal processing workstation built with Python, Tkinter, and NumPy — real-time pitch detection, convolution reverb, spectral noise reduction, MFCC-based speaker ID, sonar-style pulse-echo ranging, and more. Built as a CSE 220 final project by Team Times_Up.
Done by me - Atish(2305028) and Wasif(2305029) as our project in BUET CSE course 220, 2-2.
